# Isack GIS Portfolio

A responsive single-page portfolio website for a GIS / geospatial data professional.

## Files
- `index.html` — website structure and content
- `style.css` — responsive styling
- `script.js` — smooth scrolling

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your real email.
2. Replace the LinkedIn and GitHub placeholder links with your profiles.
3. Add real project screenshots or interactive map links if available.
4. Open `index.html` in a browser to preview.

## Publishing
The site is static HTML/CSS/JS, so it can be hosted on GitHub Pages, Netlify, Vercel, or another static hosting service.
